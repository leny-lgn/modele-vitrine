# Prompt 5 — Ajouter un secteur

---

Utilise le skill nouveau-secteur pour ajouter le secteur [boulangerie]. Commence par le
brief avec moi : pose-moi tes questions, propose 3 idées visuelles, et attends mon choix
avant de créer les fichiers. Ensuite, construis les trois gammes dans l'ordre
Essentiel, Vitrine, Premium, en t'arrêtant après chacune pour que je valide.
